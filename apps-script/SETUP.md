# 本番運用の設置手順

構成はシンプルです。お客様のスマホ → 静的なWebページ → Google Apps Script → スプレッドシート / Drive / メール。サーバーもデータベースも不要で、全部がお店のGoogleアカウントの中に収まります。

```
お客様のスマホ（QR / LINEでURLを開く）
        │  送信（回答 + 圧縮済み写真）
        ▼
Apps Script Web App  ──→ スプレッドシート（1件1行）
                     ──→ Drive（案件ごとのフォルダに写真 + answers.txt）
                     ──→ 担当者へメール通知
```

## 1. 受け皿を作る

1. Googleドライブで**スプレッドシート**を新規作成。URLの `/d/` と `/edit` の間がシートIDです。
2. 写真の保存先になる**フォルダ**を新規作成。URLの `folders/` の後ろがフォルダIDです。

## 2. Apps Script を設置する

1. [script.google.com](https://script.google.com) で新しいプロジェクトを作成。
2. `apps-script/Code.gs` の中身をまるごと貼り付ける。
3. 冒頭の3つを書き換える。

   | 定数 | 入れるもの |
   | --- | --- |
   | `SHEET_ID` | 手順1のシートID |
   | `DRIVE_ID` | 手順1のフォルダID |
   | `MAIL_TO` | 通知先メールアドレス（カンマ区切りで複数可） |

4. 右上の **デプロイ → 新しいデプロイ → 種類：ウェブアプリ**。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（お客様はログインせずに送信するため）
5. 初回は権限の確認画面が出ます。Drive・スプレッドシート・メール送信を許可してください。
6. 発行された `https://script.google.com/macros/s/…/exec` をコピー。

## 3. アプリに送信先を設定する

デザイン画面右上の **Tweaks → 送信先 → Apps Script Web App URL** に、手順2でコピーしたURLを貼り付けます。空のままだとデモ送信（実際には送られない）のままです。

設定するとアプリ側の挙動が変わります。

- 「この内容で送信する」で実際にPOSTし、送信中はボタンがロックされます。
- 失敗すると赤い帯でエラーを出し、下書きは残ります。お客様はそのまま再送できます。
- 成功すると受付番号を表示し、下書きを消去します。

## 4. 公開してQRにする

このページを静的ホスティング（お店のサイトのサブディレクトリでも、Netlify/Vercel/GitHub Pagesでも可）に置き、そのURLをQRコードにしてご案内に印刷、またはLINEで送ります。スマホのブラウザで開くだけで、インストールは不要です。

このリポジトリは GitHub Pages で公開する構成になっています。`main` ブランチの Pages を有効にすると、`index.html` がそのまま公開されます。

## データの入り方

**スプレッドシート**は1件1行。先頭に受付日時・受付番号・お店の名前・案件名・ご担当者・連絡先・Driveフォルダのリンク・写真枚数が並び、その右にシートの全設問が列として続きます。設問を増やすと列も自動で増えます。

**Drive**は `2026-08-16 紬 銀座 TSM-2026-4821` のように案件ごとのフォルダができ、`logo.jpg` `atmos.jpg` `ref1.jpg`〜`ref3.jpg` と、回答全文の `answers.txt` が入ります。写真のメモ（「ポイント：」欄）は各ファイルの説明に入るので、Driveのプレビューからそのまま読めます。

## 運用上の注意

- 写真は送信前に長辺1600pxのJPEGへ圧縮されます。店内の暗い写真でも十分な情報量で、1件あたり数百KB程度に収まります。
- 送信は `mode: 'no-cors'` で行うため、ブラウザ側では成功／失敗の詳細を受け取れません。Apps Script側の実行ログ（左メニューの「実行数」）が実際の記録です。
- 下書きはお客様の端末のブラウザにのみ保存されます。端末を変えると引き継げないため、別端末での再開が必要なら「メールで続きのURLを送る」機能の追加をご検討ください。
- Code.gs を編集したら、**新しいデプロイ**を作らないと反映されません（既存デプロイの「編集 → バージョン：新規」でも可）。
